# Video Content Management System

A complete Python-based automation system for managing video content submissions from 8 teams with fair rotation scheduling, automated email notifications, and a beautiful web dashboard.

## Features

- 🎬 **Smart Scheduling**: Fair rotation algorithm for 8 teams with 3 videos per week (Mon/Wed/Fri)
- 📧 **Email Automation**: Automated reminders at 7-day, 3-day, 1-day, and overdue intervals
- 📊 **Dashboard**: Beautiful web interface with stats, calendar, and team management
- 📅 **Calendar View**: Monthly calendar showing all scheduled submissions
- 👥 **Team Management**: Edit team info, track performance metrics
- 🔔 **Notification Center**: Email history and configuration management

## Quick Start

### Option 1: Double-click Start Script
1. Double-click `start.bat`
2. Wait for setup to complete
3. Open http://127.0.0.1:5000 in your browser

### Option 2: Manual Setup
```bash
# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
```

## Email Configuration

1. Copy `.env.example` to `.env`
2. Configure your email settings:

```env
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_EMAIL=your-email@gmail.com
SMTP_PASSWORD=your-app-password
```

### Gmail Setup
1. Enable 2-Factor Authentication
2. Go to https://myaccount.google.com/apppasswords
3. Generate an App Password for "Mail"
4. Use that password in SMTP_PASSWORD

## How It Works

### Scheduling Algorithm
- 8 teams rotate through 3 weekly slots (Monday, Wednesday, Friday)
- Each team gets approximately equal opportunities
- 12-week schedule generated by default

### Automatic Notifications
The system runs daily at 9 AM to check and send:
- **7 days before**: Assignment notification
- **3 days before**: First reminder
- **1 day before**: Urgent reminder
- **Overdue**: Overdue notification

### Manual Actions
- Click "Mark Submitted" when a team sends their video
- Click "Send Reminder" to manually send a reminder
- Click "Process Now" in Notifications to trigger all pending notifications

## API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/generate-schedule` | POST | Generate new schedule |
| `/api/mark-submitted/<id>` | POST | Mark entry as submitted |
| `/api/send-reminder/<id>` | POST | Send manual reminder |
| `/api/update-team/<id>` | POST | Update team info |
| `/api/process-notifications` | POST | Process all pending notifications |
| `/api/test-email` | POST | Send test email |
| `/api/stats` | GET | Get dashboard statistics |

## Customization

### Change Team Names
Edit `data/teams.json` or use the Teams page in the dashboard.

### Change Publishing Days
Edit `scheduler.py` line 44:
```python
submission_days = [0, 2, 4]  # Monday=0, Wednesday=2, Friday=4
```

### Change Reminder Schedule
Edit `notifications.py` function `process_scheduled_notifications()`.
